# 🎬 MovieFinder — поиск информации о фильмах

Веб-приложение для поиска информации о фильмах. Работает полностью в браузере, данные загружаются через Кинопоиск API. Позволяет просматривать популярные фильмы, искать по названию, открывать детальную информацию о фильме в модальном окне.

## 📌 Техническое задание

### Обязательные требования

- Загрузка популярных фильмов при открытии страницы
- Поиск фильмов по названию через текстовое поле
- Отображение карточек фильмов с постером, названием, годом выхода и рейтингом
- Просмотр детальной информации о фильме в модальном окне: сюжет, актёры, жанры, длительность, бюджет
- Три способа закрытия модального окна (крестик, оверлей, клавиша Escape)
- Индикатор загрузки данных
- Сообщение при пустом результате поиска
- Сообщение при ошибке соединения с API
- Адаптивный интерфейс

### Дополнительно реализованные требования

- Цветовая индикация рейтинга (зелёный / жёлтый / красный)
- Анимация появления карточек с каскадным эффектом
- Анимация наведения на карточку
- Поиск с debounce-задержкой 500 мс
- Заглушки для фильмов без постера
- Резервный каталог из восьми фильмов при недоступности API

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, медиа-запросы, CSS-переменные, анимации, backdrop-filter
- **JavaScript ES6+** — работа с DOM, Fetch API, асинхронные запросы, обработка событий
- **Кинопоиск API** — источник данных о фильмах
- **Git** — контроль версий
- **GitHub Pages** — хостинг

## 🚀 Запуск проекта

### Локально

1. Склонируйте репозиторий или скачайте архив с проектом.
2. Откройте папку проекта в любом редакторе кода (например, VS Code).
3. Запустите файл `index.html` через Live Server или просто откройте его в браузере.
4. Для корректной загрузки данных необходим доступ к Кинопоиск API. При его отсутствии приложение автоматически переключится на встроенный каталог фильмов.

## 📝 Примечания

- Приложение не требует серверной части — все данные загружаются через внешний API или из резервного массива.
- Постеры фильмов загружаются с серверов Кинопоиска. Для фильмов без постера отображается локальная заглушка.
- При недоступности API включается резервный каталог из восьми фильмов с полными данными.
